# Contributing

Contracts live in [portfolio-kit](https://github.com/PCSchmidt/portfolio-kit).

```sh
npm test
npm run eval
npm run observe
npm run architect
npm run remediate
npm run dogfood
```

Tests and eval must stay green. Do not require network in CI. Do not post GitHub comments from this repo. `npm run remediate` and `npm run dogfood` are dry-run.
